# AZI LASHES STUDIO • V04

Пересборка по замечаниям об анатомии, цельности персонажей, студии и монтаже.

- azi-lashes-v04-1080.mp4 — основной файл 1080×1920, 30 fps, H.264/yuv420p, AAC, faststart.
- azi-lashes-v04-phone.mp4 — телефонная версия 540×960.
- azi-lashes-v04-sources.zip — редактируемый проект, графика, звук, лицензии, раскадровка и инструкции.
- REPORT-v04.md — изменения, проведённые проверки и ограничения.
- contact-v04.jpg — кадры итогового декодированного фильма.

Сценарий и речь сохранены, длительность — 96,4 с. В версии 40 планов по 2–2,96 с. Старые MP4 не заменяют новую выдачу; они сохранены отдельно для истории. Озвучка остаётся временной синтетической. Новая студия — реконструкция по описанию, не точная копия отсутствующих фотографий.
