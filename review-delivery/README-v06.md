# AZI LASHES STUDIO — V06

Полный фильм: 88 секунд, 8 сцен, 30 fps. Картинка и звук подстроены под новую записанную речь. Использован одобренный пользователем вариант обработки голоса.

- `azi-lashes-v06-phone.mp4` — весь фильм 540×960 для просмотра на телефоне и пересылки.
- `azi-lashes-v06-1080.mp4` — мастер 1080×1920.
- `azi-lashes-v06-video.zip` — оба готовых MP4 и короткий отчёт одним архивом.
- `azi-lashes-v06-sources.zip` — редактируемый проект, необходимые изображения, обработанная речь, готовый микс, шрифт, монтажные ведомости и инструкции `RENDER-v06.md`.
- `azi-lashes-v06-workfiles.zip` — промежуточный полный рендер, тест движения, диагностические кадры и рабочие проверки.
- `REPORT-v06.md` — сделанные изменения, проверки и ограничения.
- `SHA256SUMS-v06.txt` — контрольные суммы.

Скачанные ZIP можно распаковать обычным архиватором. Все публичные файлы сохраняются в GitHub и доступны без работающей облачной машины. Предыдущие версии сохранены отдельно.

Анимация использует цельные иллюстрации, ключевые позы, непрерывную деформацию рисунка, комиксные крупные планы и графические реакции. Белый полноэкранный переход удалён. Приватный оригинал пользовательской записи в публичную выдачу не входит.
