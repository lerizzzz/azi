# AZI LASHES STUDIO • V05

Все файлы этой версии сохранены в GitHub. Их можно скачать и переслать независимо от соединения с облачной машиной. Предыдущие версии остаются отдельно под своими именами.

- `azi-lashes-v05-phone.mp4` — весь фильм, компактная версия 540×960 для телефона.
- `azi-lashes-v05-1080.mp4` — мастер 1080×1920.
- `azi-lashes-v05-video.zip` — оба готовых MP4, отчёт и контактный лист в одном архиве для пересылки.
- `azi-lashes-v05-sources.zip` — редактируемый проект: весь код, PNG-графика, звук, шрифт, лицензии, сценарий, требования, инструкции, отчёты и сохранённые рабочие варианты.
- `azi-lashes-v05-workfiles.zip` — дополнительные диагностические кадры, логи, тесты и промежуточный полный рендер; для обычного просмотра не нужен.
- `REPORT-v05.md` — фактические проверки и ограничения.
- `SHA256SUMS-v05.txt` — контрольные суммы скачиваемых файлов.

Персонажи перерисованы целыми позами в исходном стиле. Движения — ограниченная рисованная анимация; полноценная покадровая плавность не заявляется. Полная речь и все восемь сцен сохранены.
