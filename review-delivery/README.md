# AZI LASHES STUDIO — новый полный монтаж v03

Название: «Что делать, если в Питере вторжение пришельцев».
Восемь сцен актуального сценария; 96,4 секунды. Старые отклонённые MP4 не использованы в монтаже. Восстановленные графические ассеты переработаны в новой постановке.

- azi-lashes-film-1080.mp4 — основной 1080×1920 / 30 fps / H.264 / yuv420p / AAC / faststart.
- azi-lashes-film-phone.mp4 — сжатая версия 540×960 для телефона.
- azi-lashes-film-sources.zip — исходники, графика, WAV, лицензии, тайминг, инструкции и отчёт.
- contact-final.jpg — кадры декодированного фильма; не заменяет просмотр движения и звука.
- REPORT.md — результаты проверок и ограничения.

Озвучка RHVoice Elena — временная бесплатная синтетическая, не профессиональная актёрская запись. WELL и кабинет показаны как стилизованные реконструкции по текстовому брифу; исходных фотографий студии в восстановленных материалах не было.
