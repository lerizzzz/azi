# AZI — материалы для просмотра

Рабочая первая сцена, 34,33 секунды. Это проверка движения, не полный шестисценный фильм.

- **scene1-preview.mp4** — сжатое видео 540×960, 30 fps, H.264/yuv420p и AAC, с временной синтетической озвучкой.
- **scene1-sources.zip** — исходный проект Remotion, графические слои, готовые WAV, шрифты, лицензии и инструкции. Внутри прочитайте `remotion-film/README.md`.

На странице MP4 нажмите **Download raw file** / значок скачивания. Если браузер воспроизводит файл, его можно сохранить через меню браузера.

Полноразмерный экспорт первой сцены в рабочем проекте: 1080×1920, 30 fps, H.264. Обе версии декодированы FFmpeg без ошибок. Художественное качество и голос требуют зрительской оценки.
