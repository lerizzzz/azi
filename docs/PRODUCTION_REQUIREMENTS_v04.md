# Дополнения V04 к исходному брифу

Пользователь указал на недопустимые анатомические дефекты: одинаковые стороны конечностей, разрывы плеч/рук, таза/штанин/стоп, плавающую голову и тело мастера, руку пришельца, начинающуюся из центра корпуса, маску туши на лбу и неубедительную студию. Требуется исправлять конструкцию и её визуальный результат, не скрывать дефекты монтажом. У Ази — более длинные естественные пропорции, правильный шаг, больше эмоциональных реакций и взгляд на зрителя.

Картинка меняется через 2–3 секунды: комиксные полосы, резкие крупные планы глаз/деталей, отдаления и смены планов, больше действия. При этом композиция не должна быть перегружена. Прежний внешний видеореференс в новой машине отсутствует; пользовательские скриншоты из чата применены как конкретные случаи для проверки ошибок, но не как утверждённые новые эталоны качества.

Исходный текст, порядок событий, 1080×1920 / 30 fps / H.264 / yuv420p / AAC / faststart и правила доставки из PRODUCTION_REQUIREMENTS_v03.md остаются обязательными.
