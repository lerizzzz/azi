# Сохранённый процесс V05

Эти варианты оставлены для сохранности всей работы. Отклонённые изображения не используются в готовом фильме. Все 17 использованных PNG находятся в public/v05; их SHA-256 — в review/v05/assets.json.

Первый лист шага повторял одну фазу и был заменён. Первая попытка снятия обуви содержала три туфли; в рабочем рисунке оставлены две. Сохранены исходные варианты мужчины и мастера до повторной обработки прозрачности, а также ранний диагностический MP4 до последних корректировок положения головы/колена и испуга мужчины. Это внутренние материалы, не отдельная новая готовая версия.

Основной промежуточный picture.mp4 воспроизводится командой из README проекта. Готовый мастер 1080p и телефонный MP4 сохраняются отдельно в review-delivery и в out/v05.
