# AZI — материалы для просмотра

Две рабочие сцены для просмотра. Это проверка движения и графики, не полный шестисценный фильм.

- **scene1-preview.mp4** — сжатое видео 540×960, 30 fps, H.264/yuv420p и AAC, с временной синтетической озвучкой.
- **scene2-preview.mp4** — новый фрагмент, двор с погоней, 24,37 секунды, 540×960, 30 fps, H.264/AAC, 20 планов.
- **scene1-1080.mp4**, **scene2-1080.mp4** — версии 1080×1920, 30 fps, H.264/yuv420p и AAC.
- **scenes-01-02-sources.zip** — обновлённый исходный проект Remotion, 56 графических слоёв, три действующих рига, две сцены, WAV, шрифты, лицензии и инструкции. Внутри прочитайте `remotion-film/README.md`.
- **scene1-sources.zip** — предыдущая версия исходников только первой сцены, оставлена для истории.

На странице MP4 нажмите **Download raw file** / значок скачивания. Если браузер воспроизводит файл, его можно сохранить через меню браузера.

Внешний проигрыватель можно открыть без Remotion: замените в ссылке `https://cdn.jsdelivr.net/gh/lerizzzz/azi@COMMIT/review-delivery/scene2-preview.mp4` значение COMMIT на хеш текущего коммита этой ветки. Сервер CDN выдаёт MP4 с типом `video/mp4`; localhost и пути рабочей среды для скачивания не используются.

Экспорты проверены полным декодированием FFmpeg, а кадры контактов и переходов — по декодированным изображениям. Художественное качество и временный голос требуют зрительской оценки; перцептивное прослушивание ассистентом не выполнено. Сначала пользователь смотрит эти версии, затем выбирает дальнейшее направление.
