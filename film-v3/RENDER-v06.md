# AZI LASHES STUDIO — V06

88 секунд, 2640 кадров, 30 fps, вертикальный мастер 1080×1920.

## Открыть проект

Нужны Node.js 24, npm, FFmpeg и Chromium. Из папки проекта:

```sh
npm ci
npm run lint
npm run dev
```

Композиция: `AziFilm`. У студии встроенного аудио нет; итоговый микс хранится отдельно в `public/v06/mix.wav` и добавляется экспортом ниже.

## Получить готовое видео

```sh
mkdir -p review/v06
npx remotion render src/index.ts AziFilm review/v06/picture-1080.mp4 --browser-executable=/usr/bin/chromium --gl=swangle --concurrency=2 --codec=h264 --crf=18
python tools/export-v06.py
```

Путь Chromium при необходимости замените на установленный у вас браузер. Результаты: `out/v06/azi-lashes-v06-1080.mp4` и `out/v06/azi-lashes-v06-phone.mp4`. Скрипт проверяет полное декодирование, размеры, длительность, число кадров, цветовой формат, звук и начало воспроизведения без скачивания всего файла.

## Что сохранено

- Рисунки цельных персонажей: `public/v05`, новые реакции: `public/v06`.
- Выбранная пользователем обработанная озвучка: `public/v06/voice.wav`.
- Сведённая дорожка с музыкой и эффектами: `public/v06/mix.wav`.
- Тайминг записи, 46 планов и 77 словесных акцентов: `src/timing.json`, `src/shots-v06.json`, `src/beats-v06.json`.
- Проверки и монтажные ведомости: `review/v06`.

Озвучка получена обработкой высоты и формант исходного исполнения с сохранением его длительности. Это не новая TTS-дикторша. Пользователь прослушал пробник и одобрил этот вариант. Повторный синтез для рендера не нужен. Приватный оригинал записи в публичный архив не входит.

Архив содержит ресурсы, необходимые текущей композиции. Исторические версии V03–V05 и их исходники также остаются в репозитории. Формат анимации: цельные иллюстрации, смены ключевых поз, непрерывная деформация рисунка, комиксные вставки и графические эффекты.
